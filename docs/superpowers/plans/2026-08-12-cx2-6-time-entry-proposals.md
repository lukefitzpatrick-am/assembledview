# CX2-6 Time-Entry Proposals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After human Confirm on the `/tasks` Team tab, write one MyHours time log per Fireflies client meeting × roster attendee — never auto-write, never mix into Inbox.

**Architecture:** Fireflies sync upserts `ava_time_entry_proposals` for active `team_members` on client-attributed notes. Confirm resolves MyHours user + structure (inline ensure with link-conflict re-read), runs two-tier overlap against `time_entries`, then `POST` Create Time Log. Re-sync reconciles on `myhours_log_id`. Inbox / `ava_task_proposals` untouched.

**Tech Stack:** Next.js App Router, Drizzle/Postgres, existing `lib/myhours/client.ts` + `lib/fireflies/*`, Codex internal auth (`requireCodexInternalAccess`), `tsx --test`.

**Spec:** `docs/superpowers/specs/2026-08-12-cx2-6-time-entry-proposals-design.md` (Approved — `4ac365ec`)

## Global Constraints

- Never write MyHours entries without Confirm; Skip writes nothing.
- Inbox stays task-proposals only — no time drafts there.
- Draft eligibility = active `team_members` email match (not domain-only).
- Meeting `is_internal` = every attendee domain ∈ internal domain set (`INTERNAL_EMAIL_DOMAINS`).
- Empty/whitespace `INTERNAL_EMAIL_DOMAINS` → `DEFAULT_ASSEMBLED_DOMAINS` + config warning (never empty set).
- `entry_date` = Sydney civil date of meeting start (UTC → `Australia/Sydney`).
- Overlap: never block on same-day presence alone (two-tier guard).
- Missing MyHours user → `blocked_structure` / `no MyHours user for <email>`; re-confirm eligible.
- Ensure-structure race: unique link conflict → re-read link, do not fail Confirm.
- 401 MyHours → loud fail (`API key invalid or rotated`); no auth retry.
- Fee / bursts / `line_item_id` / published-version contracts untouched.
- Author applies SQL migrations in Supabase — do not drizzle-kit migrate from Cursor.
- Branch: `localhost`; Conventional Commits; update brain in same commits that change contracts.

- [ ] **Step 3: Implement**

```ts
import { DEFAULT_ASSEMBLED_DOMAINS } from "./attribution.js"

export { DEFAULT_ASSEMBLED_DOMAINS }

function parseCsv(raw: string): string[] {
  return raw
    .split(",")
    .map((s) => s.trim().toLowerCase())
    .filter(Boolean)
}

/** Prefer INTERNAL_EMAIL_DOMAINS; legacy FIREFLIES_ASSEMBLED_DOMAINS if unset. */
export function resolveInternalEmailDomains(
  env: NodeJS.ProcessEnv = process.env
): { domains: Set<string>; warned: boolean } {
  const raw =
    env.INTERNAL_EMAIL_DOMAINS !== undefined
      ? env.INTERNAL_EMAIL_DOMAINS
      : env.FIREFLIES_ASSEMBLED_DOMAINS

  if (raw === undefined) {
    return { domains: new Set(DEFAULT_ASSEMBLED_DOMAINS), warned: false }
  }

  const parsed = parseCsv(raw)
  if (parsed.length === 0) {
    return { domains: new Set(DEFAULT_ASSEMBLED_DOMAINS), warned: true }
  }
  return { domains: new Set(parsed), warned: false }
}

export function defaultAssembledDomainSet(
  env: NodeJS.ProcessEnv = process.env
): Set<string> {
  const { domains, warned } = resolveInternalEmailDomains(env)
  if (warned) {
    console.warn(
      "[fireflies] INTERNAL_EMAIL_DOMAINS/FIREFLIES_ASSEMBLED_DOMAINS empty — falling back to DEFAULT_ASSEMBLED_DOMAINS"
    )
  }
  return domains
}
```

export function sydneyYmdFromUtcInstant(isoOrDate: string | Date): string {
  const d = typeof isoOrDate === "string" ? new Date(isoOrDate) : isoOrDate
  if (Number.isNaN(d.getTime())) {
    throw new Error(`invalid meeting start: ${isoOrDate}`)
  }
  return sydneyCivilParts(d).ymd
}
